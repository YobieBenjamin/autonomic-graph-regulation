# Independent audit of the SAFETY repo (HEAD fc575cf, 2026-09-30)

I changed nothing in the repo. The report is also saved at `/Users/yobie_benjamin/.claude/plans/you-are-an-independent-quizzical-comet.md`.

**How I checked.** I reviewed YB-0032–0034 myself. Three read-only sub-audits covered YB-0001–0018, YB-0019–0031, and the program documents plus citations. Reruns used standalone data loaders; the committed `libcore.so` files are Linux builds that won't load on macOS, so the sub-audits rebuilt the C cores in NumPy (matching the published YB-0019 scores to within 1e-11). Tags in the table:
- **[V]**: I confirmed it myself.
- **[R]**: a sub-audit reproduced it by rerunning the analysis.
- no tag: found by reading the code or documents.

## Summary

- **The numbers are mostly honest.** Almost every number in the READMEs' Results and Verdict sections matches `results.json`. Reruns reproduced YB-0002, YB-0012, YB-0015, YB-0017, YB-0019, YB-0031, YB-0032 and YB-0033. I found no made-up numbers. A few have no data file or script behind them: the 290 ns/token cost, YB-0032's length-only control, and YB-0012's timing figures.
- **The problems are in interpretation, missing controls and disclosure:**
  - The YB-0012 and YB-0019 "earliness" claims rest on an alarm rule that also fires on most correct answers (89% and 56%). That rate was never measured.
  - Some claims about the reasoning phase alone (YB-0015, YB-0018) use features that include the answer tokens.
  - Before YB-0033, reasoning length and question type were never tested as baselines, and in several experiments they match or beat the organism.
  - Several READMEs say "Deviations: None" when there were deviations.
- **The shared layer recorder lags by one token.** Under the pinned `mlx-lm==0.31.3`, `agr/layertap.py` stores each token's layer telemetry one step late. Nothing leaks from the future, but the claim of exact alignment is false.
- **The YB-0033 headline mostly holds up, and YB-0034 replicates it, but the replication isn't written up anywhere.**
  - YB-0034 on seed 6: organism 24/43, judge 13/43, length control 11/43. Both confidence intervals are above zero, so replication (R1) holds, and the equal-false-alarm check (R2) holds too.
  - What still needs fixing:
    - The test sets exclude episodes that never produced an answer, including 61 of the 100 modpow episodes in each seed.
    - The organism's false-alarm rate is 10.12%, just over the pre-registered 10% cap.
    - Counting only episodes a monitor could actually alarm on, its false-alarm rate is 16.6%.
    - The confidence intervals ignore uncertainty in the alarm threshold.
    - The analysis code was committed together with the results, not before them.
    - YB-0034 has no README and no entry in LEDGER, PROJECT_HISTORY or RESEARCH_PROGRAM. Its pre-registered pooled estimate (R3) was never computed.
- **Citations.** The citations that are present look correctly attributed. The real gap is missing prior work on predicting errors from hidden states, which matters for the "first" and "unjailbreakable" claims.

## What checks out

- **YB-0033 numbers:** the README table, H1–H3, the equal-false-alarm values, the per-checkpoint AUROCs and the silent-slip values all match the JSON exactly. The ~500x compute ratio (488x) and "about twice" (28 vs 13) are correct.
- **No look-ahead in YB-0033/34 features:** each checkpoint only uses tokens before the answer starts, and the normalisation uses derivation data only.
- **YB-0034 design:** its code is identical to YB-0033 apart from the seed file names, as pre-registered.
- **Pre-registration timing:** test recordings start after their pre-registration commits: seed 5 began 7 s after 300f037, seed 6 71 s after c8cec65, and seed 3 (YB-0031) afterwards too.
- **Citations present:** Bashan/Ivanov 2012, NEWS2 (Royal College of Physicians 2017), Newman 2006, Scheffer 2009, Farquhar 2024, Wang 2022, Roberts 1959, Lowry 1992, Bifet & Gavaldà 2007, Kloft & Laskov 2010, Gupta 2007, Vinther 2011, Lee 2018, Liu 2020 and Sun 2009 are correctly attributed.
